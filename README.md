# Jogo do Número Secreto

Um projetinho que desenvolvi para treinar lógica de programação e JavaScript. O objetivo do jogo é bem simples: o computador escolhe um número de 1 a 10, e você tem que adivinhar qual é através de dicas dizendo se o número secreto é maior ou menor do que o seu palpite.

## Sobre o desenvolvimento

A estrutura em HTML e a estilização (CSS) foram fornecidas pelo curso de lógica da Alura. O meu foco principal aqui foi escrever toda a lógica em JavaScript do zero, o que incluiu:

- Criar a inteligência de sorteio e validação dos chutes;
- Garantir que os números não se repitam até que o ciclo feche;
- Fazer a manipulação do DOM para atualizar os textos e limpar os campos dinamicamente;
- Integrar a API do ResponsiveVoice para o jogo "falar" com o usuário.
